# Java Basic Tasks ☕

This repository contains five beginner-friendly Java programming tasks covering input/output, variables, arithmetic operations, conditional statements, and string manipulation.

## 📚 Tasks Included

1. **Hello World by Your Name**
   - Takes the user's name as input.
   - Displays a personalized Hello World message.

2. **Profit or Loss Calculator**
   - Takes Cost Price and Selling Price as input.
   - Calculates profit, loss, or no profit/no loss.

3. **Odd or Even Number**
   - Takes an integer as input.
   - Checks whether the number is odd or even.

4. **Voting Eligibility**
   - Takes age as input.
   - Checks whether the age is valid and whether the person is eligible to vote.

5. **Anagram Checker**
   - Takes two words as input.
   - Checks whether the two words are anagrams.

## 🛠️ Technology Used

- Java
- Scanner
- if / else if / else
- Variables
- Arithmetic operators
- Modulus operator (`%`)
- Arrays and `Arrays.sort()`

## ▶️ How to Run

Make sure Java JDK is installed.

Compile a program:

```bash
javac HelloWorld.java
```

Run it:

```bash
java HelloWorld
```

Similarly, compile and run any of the other Java files.
